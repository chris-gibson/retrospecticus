## Highlights

- **Upgrade collectors from the admin page.** Outdated machines get an **Upgrade** button. It is opt-in per machine: `enroll` asks, or run `retrospecticus-collector remote-update on`.
- **`retrospecticus-collector update`** installs the server's version (checksum-verified) and restarts the service, with no new approval. Rerunning the install command on an enrolled machine now does the same. The Machines tab marks outdated and retired machines.
- **oMLX** as a local embedding provider, with its own `omlx_api_key`.
- **macOS:** enrolling through `curl … | sh` no longer fails with "EINVAL: kqueue".
- The first-run setup link shows a real address you can click.
- `uninstall --purge` revokes the machine's token and removes everything it installed.

## Upgrading

- Server: `docker compose pull && docker compose up -d`.
- Collectors from 0.1.1 do not have `update` yet: rerun the install command on each machine once. From then on, `update` or the **Upgrade** button.
- Going back to 0.1.x: remove `remote_update` from `collector.json` first.
